# Визуализатор графа зависимостей (Cargo)

## 1. Общее описание

CLI-инструмент для анализа и визуализации графа зависимостей пакетов Rust
(менеджер пакетов Cargo). Зависимости получаются собственной реализацией,
без менеджеров пакетов и сторонних библиотек для работы с зависимостями.

**Текущий этап: 1 — минимальный прототип с конфигурацией.**
Приложение читает XML-конфигурацию, проверяет параметры и выводит их
в формате «ключ: значение». Сбор данных, построение графа, обратные
зависимости и визуализация (Graphviz) будут добавлены на следующих этапах.

Язык реализации: Kotlin (JVM), сборка — Gradle.

## 2. Описание всех функций и настроек

### Запуск

```
depgraph [путь/к/config.xml]
```

- Если путь не указан, используется `config.xml` из текущего каталога.
- `-h` / `--help` выводит справку и завершает работу с кодом 0.
- Принимается не более одного аргумента.

### Формат конфигурационного файла

```xml
<?xml version="1.0" encoding="UTF-8"?>
<config>
    <package_name>serde</package_name>
    <repository>https://crates.io</repository>
    <mode>remote</mode>
</config>
```

Корневой элемент — `<config>`. Все три параметра обязательны, порядок
элементов не важен. Пробелы вокруг значений отбрасываются.

### Параметры

| Параметр       | Описание                                               |
|----------------|--------------------------------------------------------|
| `package_name` | Имя анализируемого пакета                              |
| `repository`   | URL репозитория или путь к файлу тестового репозитория |
| `mode`         | Режим работы с репозиторием: `remote` или `test`       |

### Правила проверки

**`mode`** — значение `remote` или `test`.

**`package_name`** (зависит от `mode`):
- `remote` — имя Cargo: первый символ — латинская буква, далее буквы, цифры,
  `-` и `_`;
- `test` — только большие латинские буквы `A-Z`.

**`repository`** (зависит от `mode`):
- `remote` — корректный URL со схемой `http` или `https` и указанным хостом;
- `test` — путь к существующему читаемому файлу. Формат файла тестового
  репозитория будет определён на этапе 3.

**Файл конфигурации:**
- существует, является файлом и доступен для чтения;
- корректный XML (при ошибке указываются строка и столбец);
- корневой элемент называется `config`;
- все параметры заданы и не пусты.

### Коды возврата

| Код | Значение                            |
|-----|-------------------------------------|
| 0   | успех (или вывод справки)           |
| 1   | ошибка конфигурации                 |
| 2   | неверные аргументы командной строки |

Сообщения об ошибках выводятся в стандартный поток ошибок (stderr).

## 3. Примеры использования

### Успешный запуск (режим `remote`)

```
$ ./run.sh config.xml
package_name: serde
repository: https://crates.io
mode: remote
```

### Успешный запуск (режим `test`)

Конфигурация:

```xml
<config>
    <package_name>A</package_name>
    <repository>test_repo.txt</repository>
    <mode>test</mode>
</config>
```

```
$ ./run.sh config_test.xml
package_name: A
repository: test_repo.txt
mode: test
```

### Справка

```
$ ./run.sh --help
Использование: depgraph [путь/к/config.xml]
Если путь не указан, используется ./config.xml
```

### Демонстрация обработки ошибок

Файл конфигурации не найден (код 1):

```
$ ./run.sh no/such/file.xml
Ошибка конфигурации: Файл конфигурации не найден: no/such/file.xml
```

Недопустимый режим (код 1):

```
<mode>fast</mode>
Ошибка конфигурации: Недопустимый режим 'fast'. Допустимые значения: remote, test
```

Недопустимое имя пакета (код 1):

```
<package_name>bad name!</package_name>
Ошибка конфигурации: Недопустимое имя пакета 'bad name!'. Режим remote: имя
начинается с латинской буквы и содержит буквы, цифры, '-' и '_'. Режим test:
только большие латинские буквы (A-Z)
```

Некорректный URL (код 1):

```
<repository>ftp://crates.io</repository>
Ошибка конфигурации: URL репозитория должен начинаться с http:// или
https:// (получено: 'ftp://crates.io')
```

Не задан обязательный параметр (код 1):

```
Ошибка конфигурации: Не задан обязательный параметр <mode>
```

Тестовый файл репозитория не найден (код 1):

```
Ошибка конфигурации: Файл тестового репозитория не найден: no/such/repo.txt
```

Некорректный XML (код 1; текст после двоеточия формирует XML-парсер):

```
Ошибка конфигурации: Некорректный XML (строка 1, столбец 40): ...
```

Слишком много аргументов (код 2):

```
$ ./run.sh a.xml b.xml
Ошибка: слишком много аргументов командной строки
Использование: depgraph [путь/к/config.xml]
Если путь не указан, используется ./config.xml
```

Проверить код возврата можно командой `echo $?` сразу после запуска.
